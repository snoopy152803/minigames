Puzzle Admin

Editing here changes the puzzle for everyone, starting the next time each person loads a page fresh — anyone already mid-puzzle today keeps the version they started with. Each box holds one JSON array; Save is disabled until the text parses as valid JSON.

Wordle — answer words

Array of 5-letter words. This is the pool the daily/random answer is picked from (the much larger accepted-guess dictionary is not admin-editable — it lives in data/wordle/guesses/).

Strands — puzzles

Array of { theme, spangram, words } objects. spangram plus each word in words must be placeable on a grid (the game generates the letter layout automatically).

Crossword — clue database

Array of { word, clue } objects. Longer, harder words become the puzzle's anchors; include some shorter words too so the generator has room to intersect them.
