Puzzle Admin

Editing here changes the puzzle for everyone, starting the next time each person loads a page fresh — anyone already mid-puzzle today keeps the version they started with.

Wordle — answer words

One 5-letter word per line. This is the pool the daily/random answer is picked from (the much larger accepted-guess dictionary is not admin-editable — it lives in data/wordle/guesses/).

Strands — puzzles

Each puzzle needs a theme name, a spangram (the long word/phrase spanning the board), and a handful of other themed words. Plain words only — no spaces or punctuation. The board layout is generated automatically.

Crossword — clue database

A word plus its clue. Include some long/hard words (they anchor the grid) and some short ones (they fill in intersections).

WordClue

Connections — puzzles

Each puzzle needs exactly 4 groups of 4 words, easiest (yellow) to hardest (purple). One group per line, formatted as Category name: WORD, WORD, WORD, WORD. All 16 words in a puzzle must be different from each other.

Spelling Bee — letter sets

One real word per line, using exactly 7 different letters (repeats within the word are fine, e.g. "MONTHLY"). The game automatically works out every valid word and picks the best center letter from the built-in dictionary — you don't need to list words yourself. Note: "Load current" shows each puzzle's 7 letters, not necessarily the original word you typed — that's fine, just replace a line with any other real word to change that puzzle.
